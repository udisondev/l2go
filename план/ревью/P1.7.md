- Задача: P1.7 Fuzz-смоук в CI (план/p1.md) — облегчённый режим ADR-0006 (самопроверка + ворота +
  один ревьюер + владелец).
- Бюджеты: план 0/2 · ревью реализации 0/1 (облегчённый)

## План (S0)

Имеется: 3 fuzz-цели protocol (раундтрипы D/H/F/Q/S, офсеты) с seed-строками. Добавить:

1. **FuzzNextFrame** (protocol): произвольный буфер → нарезка не паникует; вернувшийся кадр —
   внутри буфера, потребление = len(body)+2; ошибки — только сентинелы
   (ErrFrameIncomplete/ErrFrameLength).
2. **FuzzLoginDecrypt / FuzzGameDecrypt** (crypto): малформенные кадры (len%8==0) через
   DecryptInit/Decrypt/SetKey-фазы → без паник, ошибки детерминированы (уже покрыто таблицами —
   фаззинг добивает неведомые входы).
3. **Seed corpus**: testdata/fuzz/<цель>/ по файлу-два в формате `go test fuzz v1` для новых целей.
4. **CI**: шаг «Fuzz-смоук» после make check — цикл по целям, `-fuzztime=10s`; заглушка-комментарий
   фазы 1 снимается.
5. **Локальный длинный фаззинг**: Makefile-цель `fuzz-long` (FUZZTIME, default 10m) с документацией.

Критерии приёмки — по плану/p1.md: CI-шаг активен и зелёный; злые входы — детерминированные ошибки
без паник (таблицы + фаззинг); находки (если будут) — регресс-тестами.
