## Раунды

- 2026-09-19 · S0/S1 · ведущая сессия · Ворота-предохранитель прогнаны покомпонентно до
  старта: зелёные (gofmt/vet/build/staticcheck/checkdeps/test -race; make на машине
  отсутствует — CI). Инвентаризация зазоров и решения S0:
  1. **S0-решение — pcap-парсер: зрелая зависимость `github.com/gopacket/gopacket`**
     (поддерживаемый форк google/gopacket, чистый Go, BSD-3 — GPL-совместима):
     `pcapgo.Reader` (классик) + `pcapgo.NgReader` (pcapng) + `layers` (диссекция
     Eth/IP/TCP). Аргументы: (а) dumpcap/Npcap владельца на Wireshark ≥3 пишет pcapng
     по умолчанию — расширение .pcap не гарантирует классик, конвертер обязан читать
     оба контейнера; (б) самопис pcapng — сотни строк (секции/блоки/опции/интерфейсы)
     без доменной ценности; (в) диссекция Eth/IP/TCP полна углов (VLAN, опции IP/TCP,
     фрагментация) — зрелый код надёжнее самописа; (г) правило убывания AGENTS: stdlib
     pcap-ридера нет → зрелая зависимость; аргумента для самописа нет (самопис оправдан
     был бы только классик-форматом, но он не покрывает pcapng). Живой захват (cgo
     libpcap) не нужен — конвертер офлайновый. Сопровождение: allowlist внешних модулей
     в scripts/checkdeps.sh + строки матрицы ADR-0005 — правкой в объёме S7.
  2. **l2tap — зазор один.** Офлайн-расшифровка уже в internal/tap/decode.go (game-нога
     ключом из KeyPacket журнала, каскад GameCrypt на направление, имена опкодов из
     каталога, JSON-фикстуры, hex-деградация без хендшейка — всё P1.6). Не покрывает
     расширенный ProtocolVersion 265 Б (опкод 0x00 + версия D + таблица патченных
     клиентов; наблюдение живого прогона KT3-3, реестр P3.7): classify требует строго
     5 байт, представление protocol.NewProtocolVersionView уже толерантно (≥5).
     S7: константа расширенного размера + классификация обоих семейств + признак
     таблицы в строке лога.
  3. **l2ini — новый кодек.** internal/l2ini (формат 413: RSA-блоки 128 Б, семейства
     ключей legacy 413 (decrypt 0x35) и modern-замена (encrypt — большая экспонента,
     decrypt 0x1d); чанковка 124/128 с байтом длины на +3 и прижимом данных к концу
     блока по align4; zlib-blob = [u32 LE распакованный размер][zlib]; хвост 20 Б с
     CRC32 LE @+12 по заголовку+шифротелу) + cmd/l2ini. Roundtrip: все слои кроме
     zlib-потока детерминированы; побайтовый roundtrip encode→decode гарантирован,
