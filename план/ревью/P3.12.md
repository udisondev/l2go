# Реестр находок P3.12

- Задача: план/p3.md §P3.12 (реплей-харнесс и CI-ворота фазы)
- Ревью-профиль: S2 — инвариантщик, конкурентщик, прагматик; S8 — + тестировщик
- Бюджеты: план 1/2 · рестарты 0/2 · ревью реализации 0/3

## Спецификация S0 (детальный план; ред. 3 — после свежего взгляда S6)

D6 как продукционная фича. ADR не нужен: исполняются D5/D6 ADR-0003 и ADR-0004
«Цена» (исходящий поток не сравнивается); тайм-тревел — OQ-8, осознанно вне фазы.

Фактура, на которую опирается план (сверено по коду):

- Ридер лога существует с P3.2: `ReadPortionLogDir` — цепочка по seq, кадры
  crc32, оборванный хвост = `ErrTruncated` после валидных записей; возвращает
  шаги и маркеры паник РАЗДЕЛЬНЫМИ слайсами — интерливинг для реплея потерян.
- Заголовок v5 несёт {версия, payloads, регион, период}; Rules свёртки
  (GraceTicks, SaveRetryTicks — входят в Leaving-дедлайны и SaveQ-NextTry,
  оба в дампе; Persist/Gateway/From — валидация отправителей писем, промах =
  DeadLetters в дампе) в логе отсутствуют → реплей с чужими дефолтами
  расходится молча (прецедент F26 про Hz — та же логика).
- Лог рождений сегодня теряет Entity.Owner (F1): Spawn ставит владельца
  собственной копии параметра, логируемая копия applyEffects — без Owner.
- Цепочка seq не знает границы сессии (F2): рестарт процесса продолжает
  цепочку, тик метронома стартует с нуля, ID акторов при детерминированном
  порядке бутстрапа совпадают → заголовки равны, ридер молча склеивает прогоны.
- Живой прогон не отдаёт дамп: `State` принадлежит горутине региона, наружу —
  только атомики `Stats()`.
- `applyEffects` актора делает со State то, что реплей обязан повторить:
  `ResolveBirth` игрока, `addLeaving` для EnterLeaving-рождений (дедлайн =
  тик + grace); Spawn/бинд/слиток — акторное, в реплее отсутствует.
- Шов времени уже существует в тестах мира: `metro.tick.Store(n)` + шаг (без
  `Metronome.Run`) — второй «источник тика» критерия приёмки.
- Дамп `State.Dump` покрывает последовательность порций счётчиками
  Steps/Letters/KindCounts и Beat-полями сущностей (каждый шаг касался их) —
  отдельная хеш-цепочка порций не нужна.
- v5-файлов в репо и тестах нет; логи возможных живых прогонов до v6 ридер
  отвергает громкой ошибкой версии (F8).

Решения:

1. **Формат v6 — заголовок несёт реплей-контракт.** Заголовок дополняется:
   sessionID (случайный uvarint, генерируется писателем при создании — вне
   свёртки, только различает прогоны; сравнение заголовков цепочки в ридере
   уже существует и превращает склейку сессий в громкую ошибку — F2),
   graceTicks, saveRetryTicks, persist, gateway, ctrlFrom. Параметр `period`
  убирается из `NewPortionLog` — единственный источник периода `Rules.PeriodNS`
   в `SetRules(Rules)` (валидация >0 там же; F5). `SetRules` вызывается из
   `Region.Wire` до старта Run (единственная точка, где Rules известны; Wire
   до Run — уже контракт; F12) и обязана пройти до первой записи кадра —
   иначе ошибка записи → заморозка региона по действующему механизму.
   Заголовок файла пишется лениво — при первом кадре: сессия без шагов не
   пишет заголовка вовсе (пустой файл ридером уже пропускается); ротация
   кодирует заголовок заново из сохранённых правил и sessionID.
   `portionVersion` 5 → 6.
2. **Ридер кадрами.** `ReadPortionFrames(dir, region) (FileHeader, []LogFrame,
   error)` — кадры в порядке записи; `LogFrame` — шаг или маркер паники;
   заголовочный регион свеяется с запрошенным (файл выбран по имени — сид RNG
   не должен молча браться из переименованного файла). `ReadPortionLogDir`
   перестраивается поверх (сигнатура/семантика прежние, потребитель — тесты
   P3.2). `FileHeader` расширяется полями контракта (включая sessionID).
3. **`world.Replay`** (`internal/world/replay.go`):
   `Replay(hdr FileHeader, frames []LogFrame, static *data.Static, gm
   *geo.Map) (ReplayResult, error)`. Валидация на входе — лог недоверен:
   `hdr.Payloads == false` → ошибка «сессия записана без payloads» (F3),
   правила из заголовка проверяются на положительность. Вход не мутируется:
   вставка рождения — глубокой копией записи (указатели Player/Npc/Transfers;
   F6). На каждый шаг: RNG `rand.NewPCG(region, tick)` (тот же, что в
   `region.step`), `Fold` с порциями в порядке записей (порядок применения
   сохранён), advisory из записи; затем применения населения: рождения —
   вставка в сортированный ents по ID из записи (несовпадение
   BirthRecord.ID и Ent.ID — ошибка разбора), `ResolveBirth`/`addLeaving` —
   общий хелпер с `applyEffects` (дрейф логики исключён); удаления — снятие
   по ID. Исходящие письма и пуши вычисляются свёрткой и отбрасываются
   (ADR-0004 «Цена»). Маркер паники обрывает достоверность: реплей
   останавливается на нём, результат несёт флаг.
   `ReplayResult{Dump, Steps, Letters, StoppedAtPanic}` — признак оборванного
   хвоста реплей не несёт: его диагностирует CLI-слой из ошибки ридера
   (`ErrTruncated` после валидного префикса — контракт P3.2); поле в
   результате Replay было бы нефальсифицируемо на юнит-уровне (T1).
   Паника внутри реплея не ловится: производственный баг = воспроизводимый
   тест (D6), глушить детектор запрещено.
4. **`Region.FinalDump()`** — дамп считается в горутине региона на выходе
   `Run`; defer его вычисления регистрируется ПЕРВЫМ (LIFO — исполнится
   последним, после финального сохранителя и закрытия лога; покрывает и
   ранний возврат при невалидных rules; финальный сохранитель State не
   мутирует — проверено). Чтение — только после остановки региона
   (happens-before через regionDone; контракт в doc-комментарии; до запуска
   Run — nil; F9). Доступно харнессу e2e через `server.region`.
5. **cmd: `-replay <каталог>`** — режим без подъёма контура: флаги `-region`
   (дефолт 1), `-artifact` (обязателен, как и живому), `-expect <файл>`.
   Читает сессию, гонит `Replay`, сверяет дамп с `-expect` бит-в-бит; при
   расхождении — первый различающийся офсет, длины и подсказка-команда
   перезаписи фикстуры. Неполный результат (`StoppedAtPanic`/`Truncated`) —
   всегда итоговая строка журнала (Steps/Letters/флаги) и ненулевой выход,
   сверка с `-expect` не выполняется (частичный дамп не выдается за полный).
   Полный результат без `-expect` — дамп в stdout (журнал — slog в stderr,
   как везде).
6. **e2e-запись с payloads.** CLI-флаг `-portions-payloads` (дефолт false —
   прод-дефолт; F3) → `config.PortionsPayloads` → `NewPortionLog`. DoD-сценарий
   выносится в хелпер (используют и смоук-тест, и записыватель фикстуры).
   - `TestReplayGateDoD`: DoD с payloads=true → после остановки: FinalDump ==
     Replay(свой лог) бит-в-бит; повторный реплей на тех же слайсах —
     бит-в-бит (критерий а + контракт иммутабельности F6); маркеров паник нет.
   - `TestReplayRecordFixture` (skip без env `L2GO_RECORD_FIXTURE`;
     skip-сообщение и текст ошибки `-expect`-расхождения несут команду
     перезаписи): пишет `cmd/l2go/testdata/replay-dod/` — цепочку логов,
     final.dump и текстовый `manifest.txt` (sessionID, поля заголовка,
     Steps/Letters, sha256 дампа и файлов логов; ревьюабельность бинарного
     диффа) + `artifact.sha256`; машинная CI-сверка sha артефакта — только
     если S7 подтвердит байт-детерминизм сборки артефакта, иначе sha в
     манифесте информационно. Фикстура в репо (десятки КБ).
   - `TestReplayFixture`: `run(["-replay", "testdata/replay-dod",
     "-artifact", synth, "-expect", "…/final.dump"])` — CLI-путь в gates.
7. **Юнит-мир (оба источника тика + слепота детектора).**
   - Синтетическая сессия (крафт через PortionLog напрямую): сессия доводит
     состояние до Logout и экспирации grace (Leaving/SaveQ непусты; F4) →
     два прогона на одних слайсах — бит-в-бит; перестановка двух писем с
     порядко-чувствительной парой ([EnterWorld, LinkDead] одного конна ↔ своп:
     EnterLeaving-рождение против DeadLetters+обычного рождения) — дамп
     меняется (критерий «детектор не слеп»); маркер паники обрывает (флаг);
     оборванный хвост — ErrTruncated ридера, CLI-слой даёт ненулевой выход
     без сверки; лог без payloads — ошибка; вторая сессия
     в тот же каталог (другой sessionID) — ошибка чтения цепочки.
   - Шов времени: регион под живым `Run` без `Metronome.Run`, тики
     инъектируются `metro.tick.Store(n)` строго возрастающими + контрольные
     письма (notify будит шаг); между инъекциями — ожидание doneTick через
     `Stats()` поллингом с бюджетом, без снов (F7) → после остановки
     FinalDump == Replay (критерий «оба источника тика»: реальный — e2e-гейт,
     шов — здесь).
8. **CI** (`.github/workflows/ci.yml`; заглушки фазы 4 не трогаются):
   - шаг «Реплей-гейт»: идёт после embed-шага и переиспользует построенный им
     синт-артефакт → `go run ./cmd/l2go -replay cmd/l2go/testdata/replay-dod
     -artifact … -expect …/final.dump` (+ сверка artifact.sha256 при
     подтверждённом детермизме сборки);
   - шаг «e2e-смоук DoD»: `go test -count=1 -v -run '^TestE2EFullDodScenario$'
     ./cmd/l2go` — повторный прогон без -race ради времени смоука в журнале
     шага (буква p3.md); -race-прогон — в make check (F10);
   - фазз-смоук: единый список целей в Makefile — цель `fuzz-smoke`/`fuzz-long`
     дополняется недостающими `FuzzLoadZones`, `FuzzLoadSkills` и новым
     `FuzzFoldSay2`; инлайн-блок ci.yml заменяется на `make fuzz-smoke`
     (комментарий-указатель на Makefile) — класс рассинхрона списков
     устранён, F11 закрывается полностью;
   - embed-шаг: + `go build -tags embedded ./cmd/...` (синт-артефакт в
     internal/artifact/embedded/; для l2login тег инертен — артефакт не
     импортируется, сборка доказывает компиляцию поставочной конфигурации).
9. **Бенчмарк**: `BenchmarkReplay` — синт-сессия (N шагов с письмами),
   ReportAllocs, `b.Loop`, baseline в `benchmarks/` (реплей — пакетный
   инструмент; бюджет — фактическая пропускная способность шагов/с).
10. **Недетерминизм-проба** (критерий «гатлинг D3»): ручная мутация в S7 —
    временная вставка с порядко-зависимым дамповидимым эффектом
    (НЕкоммутативная композиция, например `Noise = Noise*31 + …` по ключам
    map при обходе — простая сумма коммутативна и гейт не уронит) →
    реплей-гейт краснеет на детерминизм-тесте → откат; свидетельство
    (команда/вывод) — в «Раунды» этого реестра (F4).

Анти-скоуп: ретенция логов и тайм-тревел (OQ-8), много-регионные сессии и
хэндоффы, адаптивные payloads, асинхронный писатель, бисекция `-until N` —
фаза 4; сравнение исходящего потока — запрещено ADR-0004; интерфейс «для
мока» не заводится. Гейт полисит детерминизм свёртки ПОСЛЕ дрена: полноту
входа (потерянные до дрена письма) и advisory-содержимое снапшотов (факты
чтения логируются, значения — фаза 4 с многорегиональностью) он не
проверяет — осознанная граница.

Соответствие критериям приёмки (трассировка):

- бит-в-бит записанного DoD-лога + повторный прогон + мутация-перестановка →
  п.6 (e2e) и п.7 (юнит);
- недетерминизм-проба → п.10;
- оба источника тика → п.6 (реальный) + п.7 (шов);
- CI-шаги активны и зелёные, обе сборки → п.8;
- ворота зелёные → S7 (gofmt/vet/build/staticcheck/checkdeps/test -race;
  make отсутствует — покомпонентно, оговорка в PR).
