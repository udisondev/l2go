# p4 — План фазы 4: мир, который сражается

Фаза 4 по r2: грид регионов и хэндоффы, бой (урон/аггро/смерть/опыт), AI мобов,
lock-free транспорт по измерениям, AoI-событийность на полной сетке. Полный план фазы —
отдельная проработка (S0–S4 конвейера); этот файл открывается досрочно задачей P4.1 по
распоряжению владельца (2026-09-18): нагрузочный датчик перемещений показал квадрат
join-скана вырожденной ячейки (граница ~5000 движущихся, benchmarks/
P3.10-player-load-baseline.txt) — подъём сетки ячеек локален в replica и от остальных
частей фазы 4 не зависит (остаточный риск плана фазы 3 это прямо допускал).

Конвенции — [README.md](README.md); конвейер — ADR-0006, реестры — `ревью/<ID>.md`.

## Задачи

### P4.1 Сетка ячеек AoI — internal/replica, internal/world — 👀 (план утверждён конвейером, ждёт старта реализации)

**Спецификация.** Подъём вырожденной конфигурации оси 6 ADR-0004 (одна ячейка на регион)
до глобальной выровненной сетки: cellSize 8192 (≥ Exit-радиуса 4200), CellOf — чистая
функция координат; блоб несёт SoA-сегменты по ячейкам (слоты остаются глобальным
стабильным пространством издателя, манифесты — глобальные битмапы по слотам); Join — окно
3×3 наблюдателя вместо всего мира (событийный dirty-детект в пределах окна + чистка хвоста
view по cellBySlot: цель вне окна ⟹ за Exit ⟹ Remove); advisory Read — по сегменту
ячейки. Смена ячейки целью — перегруппировка сегментов, слот жив, без маркеров переезда
(внутрирегионально — не хэндофф). Детальный план — [ревью/P4.1.md](ревью/P4.1.md)
(финальный план S0, критерии/тесты/датчики — там же).

**Критерии приёмки** — по реестру P4.1 (нагрузочная цель: 10000 кластеры50 ≤ 60 мс/шаг
против текущих 361 мс; фальсификатор независимости от толпы вне окна; property-тесты
границ ячеек/гистерезиса/вырожденной конфигурации; e2e через границу ячеек; ворота).

**Ревью-профиль:** S2 — инвариантщик, перформансер, доменщик; S8 — + тестировщик.

**Зависимости:** P3.8 (replica), P3.10 (нагрузочный датчик и фикс F47).

**Ссылки:** ADR-0004 (оси 2, 3, 6; «Проверка»); ADR-0003 (D4); benchmarks/
P3.10-player-load-baseline.txt.
