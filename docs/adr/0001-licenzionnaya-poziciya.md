# ADR-0001: Лицензионная позиция — GPLv3, открытая разработка

**Статус:** accepted (решение владельца проекта, 2026-09-08).

## Контекст

Проект стоит на трёх внешних источниках:

1. **GPL-референсы** — L2J / aCis / Mobius (Java, GPLv3): формулы, структуры пакетов, поведение
   скиллов, датапак-семантика. Основной оракул для дифф-тестов.
2. **Данные, производные от NCsoft** — датапак (предметы, скиллы, NPC, спавны) и geodata.
   Не GPL: чужая интеллектуальная собственность, в экосистеме приват-серверов живёт в серой
   зоне двадцать лет.
3. **Клиент Interlude** — проприетарный; используется как чёрный ящик для проверки.

Развилка позы кода (см. r2 §Фаза 0): GPL + прямое портирование семантики против чистой комнаты
(запрет открывать GPL-исходники, поведение только чёрным ящиком).

## Решение

1. **Код l2go — GPLv3** (LICENSE в корне). Выбор версии вынужден референсами: L2J и aCis —
   GPLv3, портирование семантики с них делает производный код GPLv3-совместимым только так.
2. **Агентам разрешено открывать исходники GPL-референсов** (L2J/aCis/Mobius) и портировать
   семантику: формулы, структуры пакетов, поведение. Требование трассируемости: значимый порт
   снабжается источником в комментарии или PR (`aCis GeoEngine.canMove`, `L2J Formulas.calcPhysDam`)
   — это и лицензионная гигиена, и помощь будущей отладке.
3. **Переводится семантика, не текст.** Дословный копипаст Java в Go невозможен по языку и
   нежелателен по качеству; правило остаётся: код читается, понимается, пишется заново в
   идиоматах Go — с источником.
4. **NCsoft-derived данные не коммитятся и не распространяются проектом.** Датапак, geodata,
   файлы клиента — пользователь раздобыл сам, конвертеры/парсеры в репо работают с его копией.
   Исключение — байтовые фикстуры пакетов для golden-тестов протокола (данные интероперабельности
   уровня «структура пакета», а не контент).
5. Вклад принимается под той же лицензией; CLA не вводится.

## Отвергнутые альтернативы

- **Чистая комната** (код можно закрыть/продавать): реверс-фаза замедляется в разы — формулы
  снимаются дифф-пробингом вместо чтения; при агентной разработке и цели 10k+ это критично.
  Плюс публичный L2-сервер остаётся в серой зоне данных NCsoft независимо от лицензии кода —
  закрытость кода мало что покупает.
- **«Для себя/ресёрч»** (отложить решение): правила агентов нужны с первого порта формулы;
  смешанную историю коммитов расчистить задним числом практически невозможно.

## Последствия и цена

- Код навсегда GPL; закрытый/коммерческий вариант кода закрыт.
- Скорость реверса максимальна (главный выигрыш).
- Репозиторий чист от NCsoft-контента — «чистота» проекта проверяема: в дереве нет
  .dat/.l2j/клиентских файлов.
