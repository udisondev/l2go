# l2go

Эмулятор сервера Lineage 2 Interlude на Go. Цель — онлайн 10k+ в одном процессе;
архитектура — актор-меш регионов (single-writer + снапшоты). Проект в фазе 0
(инфраструктура доверия), кода игровой логики пока нет — см. [план/p0.md](план/p0.md).

## Карта репозитория

| Путь | Что там |
|---|---|
| `research/` | теория и дизайн-решения: r0 — архитектура мира, r1 — geodata/движение, r2 — дорожная карта, r3 — исполнение мира (тик, граница, пати) |
| `план/` | планы фаз и журнал прогресса |
| `docs/adr/` | архитектурные решения (ADR) |
| `cmd/`, `internal/` | код сервера |

## Сборка и проверка

Требуется Go ≥ 1.27.

```sh
make build   # скомпилировать всё
make check   # все ворота: build + vet + staticcheck + test -race
```

`make check` — единственная команда, которую запускают агентные сессии и CI.
