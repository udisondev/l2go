Baseline P2.7 — компилированный артефакт статики (рев. 2, после S8-дофикса)
==============================================================================
Ревизия кода: S8-дофикс (после 588b039; гварды ёмкостей поимёнными минимумами,
дети raw без резерва, общие сверки meta в Decode/LoadFile, фиксации контейнера)
Машина: рабочая станция владельца, AMD Ryzen 9 PRO 8945HS (16 потоков),
Windows 10 x64, Go 1.27.0 windows/amd64.
Команды (полный состав):
  L2GO_REAL_DATA=C:/projects/_refs/mobius-interlude/dist/game/data
  L2GO_REAL_GEO=C:/games/geodata-hi5/geodata
  go test ./internal/artifact -bench 'ArtifactDecodeReal|LoadFileRealPhases' \
      -benchmem -count=3
  go test ./internal/artifact -bench 'BuildReal' -benchmem -benchtime=3x -count=1
  (embed) артефакт полного состава кладётся в internal/artifact/embedded/:
  go test -tags embedded ./internal/artifact -bench LoadEmbeddedReal \
      -benchmem -count=3
Состав: полный дистрибутив (430 файлов; 9208 предметов, 6519 NPC, 21754
спавнов, 3630 территорий, 2411 зон, 2694 скилла / 29861 уровней) + гео
Hi5 203 региона (994 148 078 байт off-heap). Артефакт 1 012 415 800 байт
(data-секция 18 262 686 + geo-секция 994 152 954 + заголовок/meta).
Методика: фазы бенчей идут над слайсом, прочитанным в кучу ОДИН раз вне
таймера (os.ReadFile) — это тёплые фазы декодирования без транспортной
составляющей mmap (холодные page faults видны только в процессных числах
`l2data load` ниже); повторных чтений/отображений в цикле нет. BuildReal —
полный цикл encode+write с записью на диск, data-only состав, -benchtime=3x.
Медианы по -count=3: холодный первый прогон каждого счётчика гасится
медианой (сознательно, вместо warm-up итерации).

(а) Данные-к-данным: декод артефакта против парсинга XML
--------------------------------------------------------
Бенч                                ns/op (медиана)  B/op       allocs/op
BenchmarkArtifactDecodeReal            77.7 мс       59.4 МБ    1.237 млн
BenchmarkLoadReal (P2.6, та же машина) 641 мс        437 МБ     7.04 млн
Выигрыш: 8.3× по времени, 7.4× по мусору, 5.7× по аллокациям.

(б) Whole-path: тёплые фазы декодирования (benchmark) + транспорт (процесс)
----------------------------------------------------------------------------
Бенч BenchmarkLoadFileRealPhases (тёплые фазы над резидентным слайсом):
Фаза                  ns/op (медиана)   B/op       allocs/op   примечание
verify (SHA-256)      424.0 мс          32 Б       1           2388 МБ/с по ~1 ГБ
decode-data           57.0 мс           59.4 МБ    1.237 млн
decode-geo            465.7 мс          817.9 МБ   5190        heap-индексы регионов
Транспорт (процесс l2data load, холодный mmap, тёплый кеш ФС): verify=699 мс,
decode-data=84 мс, decode-geo=518 мс. Цена verify принята бюджетом
(анти-порча при хранении/передаче; crc32-Castagnoli отклонён — единый
примитив с манифестами, риск-модель не требует 10 ГБ/с). Гео-фаза равна пути
LoadDir (тот же DecodeRegion): выигрыш артефакта — data-фаза и один файл.

Embed-транспорт, полный состав (BenchmarkLoadEmbeddedReal, -tags embedded):
985–993 мс/op (медиана 988 мс), 877.2 МБ B/op, 1.242 млн allocs/op —
whole-path из rodata (verify+decode-data+decode-geo); транспортной
составляющей нет (страницы файл-бэкированы, но уже тёплые после первой
итерации).

Сборка
------
Бенч BenchmarkBuildReal (data-only артефакт 18 МБ, encode+write):
72.9 мс/op, 118.2 МБ B/op, 19.8 тыс. allocs/op (-benchtime=3x).
Полный цикл с гео — процессной командой (двумя прогонами, холодный/тёплый):
parse=3.23 с / 1.86 с (отдельно: датапак 641 мс, гео ~1.2 с), encode=1.10 с
(включая SHA по ~1 ГБ и перенос байтов гео), write=686 мс (атомарная запись
1.01 ГБ). Повторная сборка того же состава: байт-идентична, записи нет
(«актуален», write=0; сравнение по отображению, без копирования в кучу).

Синтетика (CI-состав)
---------------------

Гео-лукапы поверх байтов артефакта: 0 аллокаций (AllocsPerRun; то же —
поверх embedded-байтов, перенос критерия P2.3).
