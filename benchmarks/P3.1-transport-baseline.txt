# Baseline P3.1 internal/transport, рев. 2 (benchstat-совместимо: -count=10, -benchtime=100ms)
# Окружение: windows/amd64 (машина владельца), 16 потоков, go1.27.0 — НЕ linux, как базлайны
# P1/P2 (снимались на linux/amd64); межмашинное сравнение запрещено. Числа заголовка — медианы
# рядов; p99 заменён средним по итерациям benchstat (осознанно, F56 реестра); CV части рядов
# >15% (тихая машина разработчика) — направления выводов устойчивы, абсолюты — нет.
#
# Выбор структуры карты (спека P3.1; решение подкреплено измерениями записи, рев. 2):
#   sharded RWMutex 64 (ПОСТАВКА): Send Map0 70.4 / Map100 27.6 / Map10k 15.9 / Map50k 15.0 нс
#     (Map0 — контенция одного ящика 16 потоками, не карта; рабочий профиль — Map10k+.)
#   COW прямой индекс (1024 слота): Map10k 11.6 / Map50k 13.1 нс — чтение быстрее на ~15-27%.
#   Запись (измерено, MapWriteCompetitors): рождение COW 1482 нс против 232 нс у шарда (6.4x;
#     SyncMap 278, один RWMutex 177 — без init ящика); массовый спавн 12k: COW 72.3 мс и
#     117.7 МБ мусора против 3.05 мс и 4.8 МБ у шарда (24x) — клон 8КБ-сегмента на каждую запись.
# РЕШЕНИЕ: sharded RWMutex — перевес COW на чтении (единицы процентов ядра при пике 1M/с:
#   15.9 против 13.1 нс) не стоит цены записи и GC; пересмотр — фаза 4 по измерениям (§11).
#
# Miss-путь (измерено, F38): 1321 нс/отправка — RLock + промах + slog (заглушенный хендлер);
#   мисс — аномалия-по-построению, но лавина миссов = лог-шторм 1.3 мкс/письмо — потребителям
#   не отправлять по непроверенным id (учтено в P3.6).
#
# Бюджеты (машинные тесты): enqueue 0 аллокаций вне роста (64 B/op — амортизация сегмента);
#   изъятие пустой порции (обе ветки пустоты) и непустой в готовый буфер — 0 аллокаций.
# Enqueue serial 29.6 нс; Extract/Empty 2.7 нс; интерференция запись→чтение (батчи 12k):
#   30.7 нс против 15.9 — парковка читателей писателем RWMutex; число для фазы 4.
# Send/SendParallel гонят ящики без дрена (профиль «нет читателя», 64 B/op GC-фон) —
#   равные условия для всех кандидатов, абсолюты слегка отягощены (F60 реестра).
# Ленивый первый сегмент: MassSpawn 12k — 3.05 мс, ~400 Б и ~2 аллокации на рождение
#   (notify-канал + карта) ≈ 20 МБ на 50k сущностей против прикидки §11 5-10 МБ —
#   зафиксировано (F59), фальсифицируется фазой 4.
